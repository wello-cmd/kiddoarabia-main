## 2026-07-01 - Blocking Alerts Replaced with Modern Toasts\n**Learning:** The application used native, blocking browser `alert()` calls for form submissions and newsletter subscriptions (e.g., in `Footer.tsx`, `ContactSection.tsx`, and `AboutSection.tsx`). These native alerts severely disrupt the user experience by blocking the UI thread and looking out of place in modern web applications. They also lack accessibility features.\n**Action:** Replaced `alert()` with non-blocking `toast.success()` notifications using the existing `sonner` library integration. Explicitly added `e.preventDefault()` to `onClick` handlers within `<form>` contexts (like in `ContactSection.tsx`) to prevent unintended page reloads while still providing immediate user feedback.
